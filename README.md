# 계모임 관리 시스템

계모임(계모임) 회원들의 회칙, 입금, 지출, 경조사 등을 관리할 수 있는 모바일 최적화 웹 애플리케이션입니다.

## 주요 기능

- 👥 **멤버 관리**: 회원 정보 관리 (이름, 전화번호)
- 💰 **입금 관리**: 멤버 입금 및 은행이자 입금 관리
- 💸 **지출 관리**: 계모임 지출 내역 관리
- 🎉 **경조사 관리**: 결혼, 돌잔치, 조부모님상, 부모님상 등 경조사 지급 내역 관리
- 📊 **요약 및 통계**: 전체 잔액, 입출금 내역, 경조사 통계 확인
- ⚙️ **설정**: 전년도 이월금액 관리, 데이터 내보내기/가져오기
- 📸 **스크린샷**: 카카오톡 공유를 위한 스크린샷 기능

## 기술 스택

- React 18.2.0
- Vite 5.0.8
- React Router DOM 6.20.0
- html2canvas 1.4.1

## 설치 및 실행

### 1. 의존성 설치
```bash
npm install
```

### 2. 개발 서버 실행
```bash
npm run dev
```

개발 서버는 기본적으로 `http://localhost:5173`에서 실행됩니다.

### 3. 빌드
```bash
npm run build
```

### 4. 빌드 미리보기
```bash
npm run preview
```

## 사용 방법

1. **멤버 추가**: 멤버 관리 페이지에서 회원 정보를 추가합니다.
2. **입금 등록**: 입금 관리 페이지에서 멤버 입금 또는 은행이자 입금을 등록합니다.
3. **지출 등록**: 지출 관리 페이지에서 계모임 지출 내역을 등록합니다.
4. **경조사 관리**: 경조사 관리 페이지에서 각 회원별 경조사 지급 내역을 관리합니다.
5. **데이터 관리**: 설정 페이지에서 전년도 이월금액을 설정하고, 데이터를 내보내기/가져오기할 수 있습니다.

## 데이터 저장

모든 데이터는 브라우저의 로컬 스토리지에 저장됩니다. 다음 총무에게 인계할 때는 설정 페이지에서 데이터를 내보낸 후 전달하세요.

## GitHub Pages 배포

이 프로젝트를 GitHub Pages에 배포하려면:

1. `vite.config.js`에 `base` 경로를 추가합니다:
```javascript
export default defineConfig({
  base: '/repository-name/', // GitHub 저장소 이름으로 변경
  // ...
})
```

2. GitHub Actions를 사용하여 자동 배포하거나, 수동으로 빌드 후 `dist` 폴더를 GitHub Pages에 업로드합니다.
